# PIZZASALES
KPI REQUIREMENTS
Analyse the important KEY PERFOMANCE INDICATORS
1.	Total Revenue: SUM of the total price of all pizza orders.

2.	Average order value: The average amount spent per order, calculated by dividing the the total revenue by the total number of orders.

3.	Total pizzas sold: The sum of quantities of all pizzas sold.

4.	Total orders: The total number of orders placed.

5.	Average pizzas per order: The average number of pizzas sold per order, calculated by dividing the total number of pizzas sold by the total number of orders
